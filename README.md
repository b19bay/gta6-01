Costa Vela is an original sun-soaked coastal open-world crime game that runs entirely as static files — no build step, no network requests. Play Dario Cruz in the city of Costa Vela: work a 6-mission story chain for Mara Solis, steal cars, fight, earn money, and outrun a 1–5 star wanted system. HUD with minimap, localStorage saves, synthesized WebAudio sound.

## Run it

Open `game/index.html` in a desktop Chrome browser. That is all — the game loads from local files only.

## Layout

- `game/` — the game itself (`index.html` + `src/`)
- `screenshots/` — real captures of the running game
- `main.ts` — copies the game and screenshots to the output dossier
